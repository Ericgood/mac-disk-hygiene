# 磁盘卫生规则（给 AI 编程助手）

> 放进 AI 编程助手会读取的全局指令文件里（例如 `~/AGENTS.md`、`~/.claude/rules/common/disk-hygiene.md`）。
> 这些规则约束「你自己在本次任务里产生的东西」，不授权删除别人的东西。与其他规则冲突时，以更严格的为准。

## 1. 永远不碰（硬保护）

浏览器个人资料与缓存目录、代理/网络工具配置、AI 编程工具的配置/会话记录/认证文件、各 App 登录态与钥匙串、本地编译依赖的模拟器运行时、正在开发的源码与未提交改动。清理时不对 `~/Library/Caches/*`、`~/Library/Logs/*` 做整目录扫荡。

## 2. worktree：谁开谁收

- 每个仓库同时最多 3 个活跃 worktree。要开第 4 个，先找出已合并/已放弃的收掉（不确定就问用户，不要硬删）。
- 任务合并或放弃后，用 `git worktree remove <路径>` 收掉自己开的 worktree；有未提交改动、独有提交、或被忽略的本地独有文件（`.env*`、凭据、日志、验收材料）时不收，告诉用户。
- 不用 `rm -rf` 删 worktree，不用 `--force`，不用「移废纸篓 + prune」代替。

## 3. 依赖：能不装就不装

- 只改文档、配置、文案的任务，不跑 `npm install` / `pnpm install` / `pip install`。
- 需要依赖时优先复用主仓库已装好的；JS 项目新装优先 pnpm。

## 4. 构建产物：只留最新 3 个

- `dist/` 等放安装包的目录，每个只保留最新 3 个包（及对应 mapping）。打新包后顺手删本会话产生的最旧包。
- 要长期保留的发版包，放 NAS 或 Release，不堆在本机。

## 5. 临时文件与日志

- 放项目内 `.localtmp/`（已加入 `.gitignore`），单项目不超过 500 MB，任务结束清掉本次产生的。
- 不在 `~` 根目录、`~/.local/share` 新建目录。确实需要时，先告诉用户用途和预计大小。

## 6. 后台进程

- Android 构建：同一时间只跑一套；构建完不需要时 `./gradlew --stop`。
- 不留长期闲置的 dev server、watcher、模拟器进程；结束任务前关掉本会话启动的。

## 7. 收尾自查

任务结束前花 10 秒检查：本次是否新开了 worktree、装了依赖、产生了 >500 MB 的文件？有就按上面收掉，并在汇报里写一行「本次新增占用：xx」。

## 8. 长对话按阶段换新

一个对话只做一件事。阶段做完或对话已经很长时，把交接写进项目文档（目标、进度、下一步、踩过的坑、相关分支/worktree/构建产物、待决定事项），提醒用户换新对话；旧对话归档，不删。
